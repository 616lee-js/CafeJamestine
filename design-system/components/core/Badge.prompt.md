Always-lowercase pill for state. Pick exactly one vocabulary.

```jsx
<Badge status="resting" dot>resting</Badge>
<Badge phase="brew">Brew</Badge>
<Badge variant="secondary">Specialty drink</Badge>
```

- `status` = a thing's condition (bag, session). Indigo/lavender/mint.
- `phase` = where you are in a session. Green → red → yellow → brown, from James's espresso cups.
- Status words echo the data verbatim in lowercase; phase and type labels are sentence case.
