Renders one Lucide glyph. Requires the Lucide UMD script on the page.

```jsx
<Icon name="play" size={20} />
```

Only these glyphs appear in the product: play, plus, arrow-left, arrow-right, arrow-up, arrow-down, pencil, trash-2, copy, check, star, coffee, glass-water, chevron-down, chevrons-up-down, x, image-plus, loader-2, circle-check, octagon-x, info, triangle-alert.
